# Arena de Titanes

Juego de gladiadores por turnos en 3D (Godot 4.7, Android). Combate clásico: ataque alto/medio/bajo, defensa, poderes y pociones; forja, entrenamiento, personaje editable, logros y 12 rivales en 4 arenas.

Se actualiza desde la propia app (Releases de este repo).

Desarrollo: abrir la carpeta con Godot 4.7 y ejecutar. Pruebas: `--autoplay`, `--fight=N`, `--page=char|ach|shop|train|fights`, `--shot=ruta.png --shotframe=N`.
